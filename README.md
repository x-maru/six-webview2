# vi like text editor "six"

標準のWindows11環境で動作するvi風テキストエディタ。
スクリプトで書かれており、他にEXEやDLLは不要です。
(WebView2 runtimeというものを使いますが、Edgeの一部として標準でdownloadされているはず)

# インストール
- 配布ファイルを解凍すると出てくるフォルダがそのままインストールパスになる。
- レジストリは使わないしフォルダごと移動したりリネームしてもOK。
- install.cmdを実行するとデスクトップに起動用ショートカット"six"が作成される。
- フォルダを移したりした場合は再度install.cmdを実行する。
(install.cmdは単にショートカットを作成するだけ)

※管理者権限なし・DLL等なしで実行できます

# Vimとの大きな違い
- バッファと1対1対応のタブを持ち、split/vsplitは実装予定なし。
- 編集モード(NORMAL/INSERT/VISUAL)をタブ毎に維持する
- ウィンドウのクローズボックスなどで終了したときも次回起動時に全バッファの状態を復元する
  - 未保存のバッファの内容も復元されるので、保存しないままWindowsをシャットダウンしても大丈夫
- `$`で行末に飛んだ際、末尾の改行コードにcaretが乗る(Vim,標準viではその手前)
- `w`や`cw`などの挙動を`e`や`ce`に寄せている。`e`や`ce`は実装しない。
- CUIオンリーではないのでvimのサブセットというよりはgvimのサブセットに近いかも
  - タブ毎に異なる表示倍率にも出来る
- Vimのレジスタは内部的に一部実装しているが積極的には機能として用意しない。
- Windowsクリップボードに対応 (Yはyyではなくクリップボード版yank) ※yank:コピーバッファに格納
  - ペーストはINSERTモードでのCtrl+Vを使う
- かな・英数キーでのIME ON/OFFに限定だが、NORMALで`かな`押下で自動的にINSERTに移行するなど、制御している
- VimではINSERT中の入力はまとめて1つのundo単位だが、sixでは「編集を伴わないcaret移動」で分断してundoバッファに積んでいく。

# 制限事項・断念事項
- 「IMEがONのときだけcaretの色を変更」は「全半」キーのようなトグルだと中途半端(変更タイミングが遅れる)
- 「NORMAL/VISUALに移行したときに自動的にIMEをoffにする」もトグルだと中途半端

# Known Bugs on v0.9
- オーバーレイパレットが縦スクロールバーに接するように右余白を調整したが、稀に縦スクロールバーに重なっているときがある。
  - 発生条件はよくわからないけど、再描画タイミングでウインドウ幅の取得に縦スクロールバーが含まれるタイミングと含まれないタイミングがあるとかかな？
- prompt#666あたりの、"XYZ␊a"のaをNORMALの`s`や`cl`でcaretがXに飛んでしまい␊が消失する現象がなかなか修正完了しないので「既知の不具合」としてペンディング中。
- BOMの判定がうまく行かない(ことの方が多い)。_six.jsなどVS Codeで見るとBOMらしいけどsixではBOMなしと判定される
- 1万行を超えるとガター幅が少し足りない。
- VISUALの行選択で下から上に選択を伸ばしたとき空行を超えようとすると逆に下方向に縮んでしまう(見た目は上に伸びている)。

## 使い方
```
./six_wrap.ps1
./six_wrap.ps1 sample.txt todo.txt
```
※実際には起動しっ放しでファイルオープンはsixの独自UIを使う。

## テーマ / スタイル
- 色や:set変数の初期値などは_six.customizeで定義している。
- 設定・切替のUIは未実装。
- 編集して保存したらsixを`Ctrl+F5`でリドローすれば反映される

## 履歴
- 2025.11.25 v0.9 初版
- v0.9→v1.0
  - タブをドラッグ&ドロップで入れ替えられるようにした。
  - :b popupでの一覧表示を「ファイル名　(パス名)」に変更した。
  - 右上/右下のオーバーレイパレットを普段は透明に近い半透明にして、マウスホバー時だけはっきり見えるようにした。
  - 全角句読点クラスタ文字の一部「、。，．…」の表示幅がおかしかったのを修正した。
  - 全角丸付き数字の一部「①～⑳」がちゃんと全角で表示されるようにした(不具合ではなくフォントのせいだが、対処した)。
  - 全角括弧類や矢印も等角の全角で表示されるようにした(「」｛｝【】『』←↑↓→)。
  - 表示タブを変更した際に[検索時 A/a]ボタンの現在値が切り替わっていなかったのを修正した。
  - Shift+Ctrl+Zでウインドウを最小化するようにした。
  - INSERTモードからNORMALモードに切り替わる際に強制的にIMEをOFFにするようにした。
  - NORMALモードで`かな`キーが押下されると自動的にINSERTモードに移行するようにした。
  - 【特殊KBDユーザ向け】F19(ファンクションキー19)のキーコードをEscapeと同等に扱うようにした。
  - '/'や'?'で検索語を設定したあと`n`や`N`が実行されるまでスクロールが抑止されたままになっていた不具合を修正した。
  - INSERT中の「undoバッファへの分割格納」を実装した。編集を伴わないcaret移動で分割する。
  - VISUAL選択中の`Y`でも選択範囲を一瞬フラッシュ(協調表示)するようにした。
  - 最長行の右に2rem分の余白を設けた。常に右に2文字分の余裕も持って横スクロールする。
  - 一度も保存していない新規バッファは外部削除検出の対象にならないようにした。
  - テキスト内のURLをクリッカブルとして扱えるようにした。外部のデフォルトブラウザで開く。mailto:にも反応する。
  - テキスト内のファイルパス表記をクリッカブルとして扱えるようにした。:eで指定したものとしてsixで開く。
  - ジャンプ系以外の行スクロールを3px単位のスムーズスクロールにした。
  - caret移動を伴わない即時スクロールを追加し、`Alt+j`,`Alt+k`に割り当てた。方向はjkScrollDirectionで設定可。
  - IMEの未確定文字列があるときはその行だけ改行等の制御文字を表示しないようにした(被るので)。
  - インデント操作時の幅(shiftwidth)の選択肢に'TAB'を追加した。TABコードを挿入/削除する。SIX_OPTIONSでバッファ生成時の初期値を指定できるようにした。
  - NORMALのTABが`>>`になるようにした。VISUALのTABは`>`。Shift+TABで逆。
  - INSERTのTABでshiftwidthの設定値を挿入するようにした。2なら"  ", TABなら\t。
  - grep機能を実装した。まずはカレントバッファ内での検索。
  - 検索語履歴をセッション情報に含めるようにした。上限はSIX_OPTIONS.SEARCH_TERM_IN_SESSIONで決まる。
    - 検索語履歴は`/`,`?`のほかgrepでの検索とも共有する。
