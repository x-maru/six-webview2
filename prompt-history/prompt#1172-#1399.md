#1375
OK。
- 次は検索対象でサブディレクトリまで辿るようにしたい。
  - `-r`で「再帰」を指定
  - `-depth` で最大階層
    - `-r`がないときは無意味。`-r -depth 2`なら基点ディレクトリとその下のサブディレクトリまで。
  - `-r`を指定したときは基点ディレクトリを`-path`で指定する(ワイルドカード無し)
    - `-r -path ..`も`-r -path ../`も同じ
  - `-r`がなくても`-path`は有効
  - `-path パス`の他にワイルドカードやファイル名があれば検索対象とみなす
  - `-path パス`の他に検索対象の指定がなければ'*'として扱う
  - オプションは順不同 (-depthの後ろには階層、-pathの後ろにはパスが必須)
  - 例）
    - `:grep -r /word/ -path ../ s*/*.md`
    - `:grep -r -depth 3 /word/ -path ../`
    - `:grep -r /word/ ..`
    - `:grep /word/ -path ../ s*/*.md -r`
    - `:grep /word/ -r -path ../ s*/*.md`
    - `:grep /word/ -path ../ -r s*/*.md`
  - 検索結果バッファのヘッダ「対象」の上に「基点」を追加。-pathの値。(%のときは'ー')
  - 検索結果バッファのヘッダ「対象」の下に「再帰」を追加。値は'YES'/'NO'/ー (%のときは'ー')
  - 検索結果バッファのヘッダ「再帰」の下に「最大階層」を追加。値は数字/ー (有効な-depthが無いときは'ー')

    - ①":grep [-r [-maxpath N]] /REGEXP/[OPTION] -basedir DIR[/] [`検索対象ファイル(ワイルドカード可)`"]
      - ①-1)`[-r [-maxpath N]]`, `/REGEXP/[OPTION]`, `-basedir DIR[/]` は順不同
        - OK)":grep -r -maxpath 3 -basedir DIR /REGEXP/ `検索対象ファイル`
        - OK)":grep /REGEXP/ -r -maxpath 3 -basedir DIR `検索対象ファイル`
        - OK)":grep /REGEXP/ -basedir DIR -r -maxpath 3 `検索対象ファイル`
      - ①-2)検索対象ファイルを省略すると"*"として扱う
        - OK)":grep -r /REGEXP/ -basedir ."
      - ①-3)`-maxpath`なしで`-r`を指定するのは可(階層の上限なし)
        - OK)":grep /REGEXP/ -r -basedir /A/ *.TXT"
      - ①-4)検索対象ファイルに'/'が含まれているとエラー扱い
        - NG)":grep -r -maxpath 9 /REGEXP/ -basedir /A/B FOO/*.TXT"
      - ①-5)basedirにワイルドカードを含むのはNG
